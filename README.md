# Entertainment Marketplace (Aus Lanka)

Movie rentals + streaming, event discovery and ticket / concert-pass sales for Sri Lanka.

| Folder | What | Status |
| --- | --- | --- |
| `backend/` | Laravel 12 API (modular monolith, REST `/api/v1`) | Milestone 1 foundation in progress |
| `mobile/` | Customer app — React Native + Expo | Not started (Sprint 2–3) |
| `portal/` | Admin + organizer web portals — Next.js | Not started (Sprint 3) |
| `scanner/` | Gate-staff QR scanner app — Expo | Not started (Sprint 6) |
| `docs/` | Architecture, API conventions, decisions | Living |

The delivery plan (sprints, backlog IDs A01–K10, milestones, open decisions) lives in the
"Entertainment Marketplace – Delivery Plan" sheet. Commit messages and PRs reference backlog IDs, e.g. `C01: login + token lifecycle`.
